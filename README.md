# Portfolio files

Copy these into the project you created with `npx create-next-app@latest my-portfolio`
(TypeScript, Tailwind, App Router, and the `@/*` import alias = Yes).

Replace/add:
- app/layout.tsx, app/page.tsx, app/globals.css  (replace the existing ones)
- components/  (new folder in the project root)
- lib/         (new folder in the project root)

Then run `npm run dev`.

To change your content, only edit lib/content.ts.
Put your resume at public/resume.pdf.
