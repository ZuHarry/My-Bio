# Portfolio files (Glow-Up theme)

Copy into the project created with `npx create-next-app@latest my-portfolio`
(TypeScript, Tailwind, App Router, "@/*" alias = Yes).

- Replace app/layout.tsx, app/page.tsx, app/globals.css
- Add the components/ and lib/ folders to the project root
- Add public/resume.pdf, and later public/photo.jpg

Run `npm run dev`. All text lives in lib/content.ts.
Photo: set `photo: "/photo.jpg"`. Project screenshots: set `image: "/projects/name.png"`.
